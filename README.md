# INFINITI GLASS - Complete Glass & Aluminium Solutions

A modern, responsive website for INFINITI GLASS, showcasing architectural glass and aluminium solutions. Built with React, Vite, and Tailwind CSS 4.0.

## 🚀 Features

- **Modern UI/UX**: Premium "Steel & Glass" architectural design.
- **Dynamic Pages**: Optimized for Home, Services, Products, and Gallery.
- **Interactive Forms**: Request service and quote forms.
- **Role-based Dashboards**: Custom interfaces for both Customers and System Administrators.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.

## 🛠️ Tech Stack

- **Frontend**: React 19 (Vite)
- **Styling**: Tailwind CSS 4.0 (Vite Plugin)
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Fonts**: Google Fonts (Outfit & Inter)

## 🏗️ Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

1. Clone or download the repository.
2. Open your terminal in the project folder.
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

Start the local server with:
```bash
npm run dev
```

The website will be available at [http://localhost:5173](http://localhost:5173).

## 📁 Project Structure

- `src/components`: Reusable UI components (Navbar, Footer, Hero, etc.)
- `src/pages`: Main application views and dashboards.
- `src/assets`: Images and static resources.
- `src/index.css`: Tailwind 4 theme configuration.
